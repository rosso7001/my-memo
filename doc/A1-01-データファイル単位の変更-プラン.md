# プラン：データファイル単位の変更（年単位 → 年月単位）

## 概要

現在は年単位（`2026.md`）で管理しているメモデータを、年月単位（`202611.md`）に変更する。
あわせて、画面上部にYYYYMMを選択できるプルダウンを追加し、選択中のファイルのメモを一覧表示する。

既存の `2026.md` は `202611.md` に置き換える（移行・併存なし）。

---

## サブタスク一覧

### サブタスク1：`memo.js` のファイル名生成関数を年月対応に変更

- **Status**: `[x] done`

**Intent**  
`currentYearFile()` が返すファイル名を年単位から年月単位に変更する。

**Expected Outcomes**  
- `currentYearFile()` が `"202611.md"` 形式の文字列を返す
- 関数名を `currentYearMonthFile()` にリネームし、`app.js` 側のインポートも更新する

**Todo List**  
1. `memo.js` の `currentYearFile()` を `currentYearMonthFile()` にリネームし、戻り値を `YYYYMM.md` 形式に変更
2. `app.js` のインポート文と呼び出し箇所（`currentYearFile()` → `currentYearMonthFile()`）を更新

**Relevant Context**  
- [`frontend/js/memo.js`](../frontend/js/memo.js) — `currentYearFile()` 関数（末尾付近）
- [`frontend/js/app.js`](../frontend/js/app.js) — インポート行1行目、`loadMemo()`・`saveMemo()` 内の呼び出し箇所

### サブタスク2：`api.js` にファイル一覧取得関数を追加

- **Status**: `[x] done`

**Intent**  
GitHub API の contents エンドポイント（`GET /repos/{owner}/{repo}/contents/data`）を使い、`data/` ディレクトリ内のファイル名一覧を取得する関数を追加する。

**Expected Outcomes**  
- `fetchFileList()` を呼ぶと `["202610.md", "202611.md"]` のような配列（ファイル名のみ、`.md` 拡張子付き）が返る
- ディレクトリが存在しない（404）場合は空配列を返す

**Todo List**  
1. `api.js` に `fetchFileList()` を追加する
   - `GET /repos/{owner}/{repo}/contents/data` を呼び出す
   - レスポンスの配列から `name` プロパティを抽出して返す
   - 404 の場合は `[]` を返す

**Relevant Context**  
- [`frontend/js/api.js`](../frontend/js/api.js) — `fetchFile()` の実装パターンを踏襲する

### サブタスク4：`app.js` にプルダウン制御ロジックを追加

- **Status**: `[x] done`

**Intent**
初期表示時にプルダウンをファイル一覧で埋め、現在年月を初期選択状態にする。
プルダウン切り替え時に選択ファイルのメモを再ロードする。

**Expected Outcomes**  
- 画面起動時に `fetchFileList()` でファイル一覧を取得し、プルダウンに表示される（新しい順）
- 現在年月（`202611` 等）が初期選択される。一覧にない場合は先頭を選択
- プルダウン変更時に選択した `YYYYMM.md` のメモ一覧が表示される
- 追加・保存は常に「プルダウンで現在選択中のファイル」に対して行われる

**Todo List**  
1. `api.js` から `fetchFileList` をインポートに追加
2. `loadMemo()` を `loadMemo(file)` のように引数を受け取る形に変更し、`currentYearMonthFile()` はデフォルト値として使用する
3. `saveMemo()` も `file` 引数を受け取る形に変更し、プルダウン選択値を使うようにする
4. `initMonthSelect()` 関数を追加する
   - `fetchFileList()` でファイル一覧を取得
   - `<select>` に `<option>` を生成（ファイル名から `.md` を除いた値を表示）
   - 現在年月が一覧にあれば選択、なければ先頭を選択
   - `change` イベントで `loadMemo(選択値 + ".md")` を呼ぶ
5. `showMain()` 後の `loadMemo()` 呼び出しを `initMonthSelect()` 呼び出しに変更

**Relevant Context**  
- [`frontend/js/app.js`](../frontend/js/app.js) — `loadMemo()`・`saveMemo()`・`showMain()`・初期化処理（`DOMContentLoaded`）
