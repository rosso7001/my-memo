# 音声入力（Speech-to-Text）まとめ

## 目的
フロントエンド（HTML/JS）のテキストエリアにマイクボタンを設置し、声でメモ入力できるようにする。

---

## 結論：Web Speech API 一択

| 項目 | 内容 |
|------|------|
| コスト | 完全無料・永久無料 |
| APIキー | 不要 |
| 追加ライブラリ | 不要 |
| 対応ブラウザ | Chrome / Edge（Safariは部分対応、Firefox非対応） |
| 日本語対応 | ✅ |
| リアルタイム認識 | ✅ |
| HTML/JSのみで実装 | ✅ |

---

## 実装サンプル

```html
<textarea id="memo" rows="5" placeholder="メモを入力..."></textarea>
<button id="mic">🎤</button>

<script>
const recognition = new (window.SpeechRecognition || window.webkitSpeechRecognition)();
recognition.lang = 'ja-JP';
recognition.interimResults = false;

let isListening = false;
const btn = document.getElementById('mic');
const textarea = document.getElementById('memo');

btn.addEventListener('click', () => {
  if (!isListening) {
    recognition.start();
    btn.textContent = '⏹️';
    isListening = true;
  } else {
    recognition.stop();
    btn.textContent = '🎤';
    isListening = false;
  }
});

recognition.onresult = (e) => {
  textarea.value += e.results[0][0].transcript;
};
</script>
```

## 比較検討した他の選択肢

| サービス | 無料枠 | フロントから直接接続 | APIキー | 備考 |
|---------|--------|-------------------|--------|------|
| **Web Speech API** | 完全無料 | ✅（キー不要） | 不要 | 今回の採用案 |
| Deepgram | 月200時間 | ✅（WebSocket） | 必要⚠️ | キーがブラウザに露出するリスクあり |
| AssemblyAI | クレジット付与 | ✅ | 必要⚠️ | 同上 |
| Whisper（ローカル） | 完全無料 | ❌（バックエンド必要） | 不要 | Python環境が必要 |
| Google STT API | 月60分 | ❌（バックエンド推奨） | 必要 | GCP登録要 |

---

## 注意点

- **APIキーをフロントに直書きするのは危険**（Deepgram等）。悪用されると意図しない課金が発生する。
- Web Speech API は内部的にGoogleのサーバーへ通信しているが、ユーザー側での管理は不要。
- Chrome / Edge 以外のブラウザ対応が必要な場合は、バックエンド経由でWhisperを使う構成が最善。
