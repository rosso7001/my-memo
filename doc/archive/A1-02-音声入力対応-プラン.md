# A1-02 音声入力対応 プラン

## 概要

テキストエリアの横にマイクボタンを設置し、Web Speech API を使って音声をテキストに変換してテキストエリアへ入力できるようにする。
追加要望として、URL クエリパラメータ（例: `?mic=1`）により、ページ表示直後からマイク入力がONの状態で起動できるようにする。

追加ライブラリは不要。既存の HTML / CSS / JS のみで完結する。

## Sub-Task 3: 音声入力ロジックの実装（JS）

- **Status**: [x] done

### Intent

`app.js` に Web Speech API を使った音声認識ロジックを追加する。
マイクボタンのクリックでトグル（ON/OFF）し、認識結果をテキストエリアに追記する。

### Expected Outcomes

- マイクボタンをクリックすると音声認識が開始し、ボタンが `⏹️` に変わり `.listening` クラスが付く
- もう一度クリックすると認識が停止し、ボタンが `🎤` に戻り `.listening` クラスが外れる
- 認識結果がテキストエリア（`#add-input`）の末尾に追記される
- ブラウザが Web Speech API 非対応の場合はボタンを非表示にする

### Todo List

1. `app.js` に `initSpeechInput()` 関数を作成し、以下を実装する
   - `window.SpeechRecognition || window.webkitSpeechRecognition` の有無チェック
   - 非対応なら `#btn-mic` を `display:none` にして終了
   - `recognition.lang = 'ja-JP'`、`interimResults = false` で設定
   - `recognition.continuous = true` にして連続認識を有効化
   - `recognition.onresult` で `#add-input` に transcript を追記
   - `#btn-mic` のクリックでトグル（start / stop）し、ボタンアイコンと `.listening` クラスを切り替え
2. `DOMContentLoaded` 内で `initSpeechInput()` を呼び出す

### Relevant Context

- [`frontend/js/app.js`](../frontend/js/app.js) — `DOMContentLoaded` ブロック（260行目付近）
- [`my-memo/doc/20261126-音声入力まとめ.md`](./20261126-音声入力まとめ.md) — 実装サンプル・注意点

## Sub-Task 4: URL引数によるマイク自動ON対応（JS）

- **Status**: [x] done

### Intent

URL クエリパラメータ `?mic=1` が付いている場合、ページ読み込み直後に自動でマイク入力を開始する。
音声入力でメモを素早く追加したい場面（例: スマートフォンショートカットからの起動）を想定。

### Expected Outcomes

- `?mic=1` でアクセスすると、ページ表示直後に音声認識が自動的に開始される
- 自動ONの場合もボタンアイコンと `.listening` クラスはトグル時と同様に更新される
