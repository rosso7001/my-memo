# マイWEBメモ 検証手順

## 前提条件

- GitHub アカウントを持っていること
- Git がローカルにインストールされていること
- 検証用ブラウザが使用可能なこと（Chrome / Edge 推奨）

---

## Step 1：GitHub リポジトリの作成

### 1-1. データリポジトリ（my-memo-data）

1. GitHub で新規リポジトリを作成
   - リポジトリ名：`my-memo-data`
   - 公開設定：**Private**
   - README は作成しない（空のまま）

2. ローカルの `my-memo-data/` を push する
   ```bash
   cd {ワークスペースルート}/my-memo-data
   git init
   git add .
   git commit -m "initial commit"
   git remote add origin https://github.com/{owner}/my-memo-data.git
   git push -u origin main
   ```

### 1-2. ソースリポジトリ（my-memo）

1. GitHub で新規リポジトリを作成
   - リポジトリ名：`my-memo`
   - 公開設定：**Private**（GitHub Pages は Private でも使用可能）
   - README は作成しない（空のまま）

2. ローカルの `my-memo/` を push する
   ```bash
   cd {ワークスペースルート}/my-memo
   git init
   git add .
   git commit -m "initial commit"
   git remote add origin https://github.com/{owner}/my-memo.git
   git push -u origin main
   ```

---

## Step 2：GitHub Pages の設定

1. `my-memo` リポジトリの Settings → Pages を開く
2. Source を **Deploy from a branch** に設定
3. Branch：`main` / Folder：`/frontend` を選択して Save
4. 数分待つと `https://{owner}.github.io/my-memo/` で公開される

---

## Step 3：Fine-grained PAT の発行

1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
2. **Generate new token** をクリック
3. 以下のように設定する

   | 項目 | 設定値 |
   |---|---|
   | Token name | my-memo-token（任意） |
   | Expiration | 任意（90日など） |
   | Resource owner | 自分のアカウント |
   | Repository access | **Only select repositories** → `my-memo-data` のみ選択 |
   | Permissions → Contents | **Read and write** |

4. Generate token → トークン文字列（`github_pat_xxx...`）をコピーして保管

---

## Step 4：初期設定（ブラウザ）

1. `https://{owner}.github.io/my-memo/` をブラウザで開く
2. 初期設定画面が表示されるので以下を入力

   | 項目 | 入力値 |
   |---|---|
   | Personal Access Token | Step 3 で発行した PAT |
   | リポジトリオーナー | 自分の GitHub ユーザー名 |
   | データリポジトリ名 | `my-memo-data` |

3. **保存して始める** をクリック

---

## Step 5：動作確認

### 5-1. 追加
1. 入力エリアに任意のテキストを入力（Markdown 記法も試す）
   ```
   # テスト見出し
   本文テキスト
   - リスト1
   - リスト2
   ```
2. **追加** ボタンをクリック
3. ✅ エントリが一覧の先頭に表示される
4. ✅ GitHub の `my-memo-data/data/2026.md` にコミットが追加されていることを確認

### 5-2. 編集
1. 追加したエントリの **編集** ボタンをクリック
2. ✅ テキストエリアにエントリ内容が展開される
3. テキストを修正して **保存** をクリック
4. ✅ 本文が更新されて再描画される
5. ✅ 日時タグが変わっていないことを確認

### 5-3. 削除
1. エントリの **削除** ボタンをクリック
2. ✅ 確認ダイアログが表示される
3. OK をクリック
4. ✅ エントリが一覧から消える
5. ✅ GitHub の `2026.md` からも該当エントリが除去されていることを確認

### 5-4. Markdown レンダリング確認
- `#` → h1 として表示されること
- `##` → h2（左ボーダー付き）として表示されること
- `-` → リストとして表示されること
- `**太字**` → 太字として表示されること
- ` `` ` → インラインコードとして表示されること

### 5-5. 設定変更
1. 右上の ⚙ ボタンをクリック
2. ✅ 設定画面が開き、現在の設定値が表示されること
3. キャンセルをクリックしてメイン画面に戻れること

### 5-6. 複数端末確認（任意）
1. 別のブラウザ / 別の端末で同じ URL を開く
2. 設定画面で同じ PAT / owner / repo を設定
3. ✅ 同じメモ一覧が表示されること
4. 片方で追加 → もう片方でリロードして反映されること

---

## 確認ポイント（エラー発生時）

| 症状 | 確認箇所 |
|---|---|
| 画面が開かない | GitHub Pages の公開状態・`frontend/` の指定 |
| 「読み込みエラー」が出る | PAT の権限・owner / repo の入力値 |
| 追加後に画面が更新されない | ブラウザの console でエラー確認 |
| 保存エラー 409 | SHA 不一致（短時間に連続保存した場合）→ リロードして再試行 |
| 保存エラー 401 | PAT の有効期限切れ or 権限不足 |
