
# 機能追加一覧

## A1-01-データファイル単位の変更（✅ 製造／✅ 設計）

- 現在は年単位でデータファイルを管理しているが、年月単位に変更する
- 画面上の入力エリアの上にYYYY年MM月を選択できるプルダウンを追加する
    - 初期表示は現在のYYYYMMを選択した状態とする
    - my-memo-dataに存在しているmdファイルの数だけプルダウンに表示する
    - プルダウンで選択したYYYYMM.mdファイルの内容のメモを一覧表示する

## A1-02-音声入力対応（✅ 製造／✅ 設計）

- 現在はメモの追加は文字入力のみによって行われている
- マイクボタンを設置して音声入力によりテキストエリアに文字おこしができるようにしたい
- 基本方針は同フォルダの20261126-音声入力まとめ.mdに記載してある
- また追加要望として、URL引数などの制御により最初からマイク入力がONになっている状態での表示を可能としたい

## A1-03-データファイルのマージ機能（✅ 製造／✅ 設計）

- 過去のデータファイルについてはマージ可能とする
    - メモ一覧の下にファイルマージというボタンを設置する
    - ボタン押下によりその年月のファイルを他のファイルにマージする
    - マージルール
        - 該当の年月から一番直近の未来年月のファイルの末尾にマージする
            - 202605 マージされる側のファイル(202605の下に202602のデータがマージされる)
            - 202602 マージ対象のファイル(ボタン押下)
            - 202601 過去なのでマージ対象ではない
        - 上記ルールにすることにより、どこからでもどのような順番でもファイル内では最終的には日付順に逆ソートされた状態のファイルとなる(ここが重要)
