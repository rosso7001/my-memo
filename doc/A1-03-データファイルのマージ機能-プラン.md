# A1-03 データファイルのマージ機能 プラン

## 概要

過去月のデータファイルを、より新しい月のファイルの末尾にマージする機能を追加する。

- メモ一覧の下に「ファイルマージ」ボタンを設置する
- ボタン押下により、表示中のファイル（マージ元）の内容を「直近の未来月ファイル」（マージ先）の末尾に追記する
- マージ元ファイルは削除する
- 各ファイル内のエントリは常に降順で管理されているため、マージ元を末尾に付けるだけで全体の降順が維持される
- 当月ファイル選択時はボタンを非表示にする（当月より未来のファイルは存在しないため）

## Sub-Task 3: `app.js` にマージ処理ロジックを追加

- **Status**: [x] done

### Intent

「ファイルマージ」ボタン押下時に、表示中ファイルの内容を直近の未来月ファイルの末尾にマージし、マージ元ファイルを削除する。

### Expected Outcomes

- マージ先ファイル（現在の YYYYMM より大きい最小の YYYYMM）を特定できる
- マージ先エントリの末尾にマージ元エントリを連結して保存できる
- マージ元ファイルが削除される
- マージ完了後、プルダウンを再構築して当月ファイルを表示する
- マージ中はローディング表示、完了・エラーはステータスメッセージで通知する

### Todo List

1. `api.js` から `deleteFile` をインポートに追加する
2. `findMergeTarget(currentFile, fileList)` を実装する
   - `fileList` から `currentFile` より大きい YYYYMM を持つファイルを抽出し、最小のものを返す
3. `onMergeClick()` を実装する
   - `findMergeTarget()` でマージ先を特定する
   - マージ先・マージ元それぞれ `fetchFile()` で内容と SHA を取得する
   - `parseEntries()` で両ファイルをパース
   - `[...destEntries, ...srcEntries]` で連結する（ソート不要）
   - `entriesToMd()` → `saveFile()` でマージ先を上書き保存する
   - `deleteFile()` でマージ元ファイルを削除する
   - `initMonthSelect()` を呼び出してプルダウンを再構築する
4. `loadMemo()` 内のボタン表示制御に `.merge-area` を追加する
   ```js
   document.querySelector('.merge-area').style.display = isCurrentMonth ? 'none' : 'block';
   ```
5. `DOMContentLoaded` 内で `#btn-merge` の click イベントに `onMergeClick` を登録する

### Relevant Context

- [`frontend/js/app.js`](../frontend/js/app.js) — `loadMemo()`（101行目付近）・`DOMContentLoaded` ブロック（321行目付近）
- [`frontend/js/memo.js`](../frontend/js/memo.js) — `parseEntries()`・`entriesToMd()`
